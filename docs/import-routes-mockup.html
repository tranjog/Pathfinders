Import Route — design mockup

Three states of the import flow as it slots into the existing Route-mode side panel. Theme shown: cycling. The flow lives next to Saved Routes; on import, the file is parsed, validated, previewed, then stored as a saved route under the currently selected activity (cycling here) and immediately drawn on the map.

Pick file (.gpx / .kml / .geojson) → Parse + validate → Preview dialog → Save (current activity) + render

3 — Validation error states

Errors block the import; warnings (above) just inform.

Couldn't import file

broken.gpx
No valid track points found.
  • File parsed but contained 0 <trkpt> / <rtept> elements with valid lat/lng.

Validation rules summary

  • Reject: > 10 MB, unsupported extension, parse failure, < 2 valid points.
  • Auto-fix: drop NaN / out-of-range coords, downsample > 50k points, join multi-segment tracks.
  • Warn (non-blocking): joined segments, synthesized stops from endpoints, bounding box > 5 000 km diagonal.
